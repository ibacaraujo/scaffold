# Scaffold

Os pré-requisitos das aulas de [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html), de Andrej Karpathy, em lições curtas com código, para quem nunca programou. Um projeto da Bragat.

O Scaffold não refaz as aulas: ensina o que cada uma assume que você já sabe e mostra onde aquilo aparece nela. Não é afiliado ao curso.

Site estático, sem servidor: o Python roda no navegador (Pyodide) e o progresso fica no aparelho. O conteúdo está em `licoes.js`.

Para rodar localmente: `python3 -m http.server` nesta pasta.
